🔹 Project Overview

Developed a microservices-based backend system for a marble exporting company including:

Public website APIs

Separate Admin/ERP-style dashboard backend

Order management & tracking system

Sales and employee operational system

🔹 Responsibilities & Achievements

Designed and implemented ~70 RESTful APIs

Built microservices architecture separating:

Authentication Service

Orders Service

Products Service

User Management Service

Implemented Role-Based Access Control (RBAC) for:

Sales team

Employees

Admins

Developed ERP-like features:

Invoice generation

Packing & shipping workflow

Order tracking & status updates

Sales data management

User data modification

Designed relational database structure using PostgreSQL

Integrated MongoDB for flexible document-based data

Deployed production services using Vercel & Fly.io

Implemented secure authentication using JWT

Structured the system following Clean Architecture principles

Built full backend for separate Admin Dashboard
